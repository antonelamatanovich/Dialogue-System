# Dialogue System Package

Dialogue System Package is a reusable Unity package that provides a modular dialogue framework built around Scriptable Objects, reusable architecture, and event-driven programming.

The project was developed as part of the **ER-EL Winter Semester 2024 – Depths of Unity** elective course within the **Bachelor of Arts in Expanded Realities** study programme at **Darmstadt University of Applied Sciences (h_da), Germany**.

The course focused on designing reusable Unity systems, applying software engineering principles, and implementing common design patterns to build maintainable and extensible development tools rather than complete game experiences.
